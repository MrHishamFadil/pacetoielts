# Pace to IELTS — design explorations

Isolated visual prototypes, not a production redesign. Open index.html and use the three theme buttons. Direct selections: ?theme=studio, ?theme=academy, ?theme=labtheme.

All three use original CSS artwork and system fonts; no paid assets, dependencies, tracking or external requests. Existing website pages are linked using relative paths. The skills snapshot is explicitly illustrative. No authentication, scores, forms or student data are connected.

Branch: design/ielts-theme-explorations. Production files are unchanged. Do not merge until a direction is selected and the complete site is adapted and tested.

Preview by checking out this branch and running `python3 -m http.server 8000` from the repository root; visit http://localhost:8000/design-explorations/.
